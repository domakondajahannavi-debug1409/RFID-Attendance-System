# RFID Based Smart Attendance System

## Overview
An RFID-based attendance system using Arduino for student attendance tracking.

## Components Used
- Arduino Uno
- RFID Reader
- RFID Tags
- LCD Display
- Bluetooth Module

## Features
- RFID card scanning
- Student attendance marking
- Duplicate scan detection
- LCD attendance display
- Serial communication support

## Skills Used
- Embedded C
- RFID Interfacing
- LCD Interfacing
- Arduino Programming
- Serial Communication
